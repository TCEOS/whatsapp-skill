# Vincular tu número con el código (pasos para el usuario final)

El agente te mostrará un código con el formato **XXXX-XXXX**. Haz esto en tu teléfono:

1. Abre **WhatsApp** en tu teléfono.
2. Ve a **Ajustes** (iPhone) o toca los **⋮ tres puntos** (Android) > **Dispositivos vinculados**.
3. Toca **Vincular un dispositivo**.
4. Elige **Vincular con el número de teléfono** (en lugar de escanear QR).
5. Escribe el código **XXXX-XXXX** que te dio el agente.
6. Mantén el flujo abierto mientras el agente verifica la conexión.
7. Confirma que desapareció **Logging in...** y que el dispositivo aparece en **Dispositivos vinculados**. Las credenciales guardadas no prueban que este paso haya terminado.

Notas:

- El código dura solo unos minutos. Si vence, pide uno nuevo al agente.
- No compartas el código con nadie más.
- Para desvincular después: WhatsApp > Dispositivos vinculados > toca la sesión > Cerrar sesión.
